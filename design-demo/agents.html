智能体页 v2 — Orb 动态头像体系

AI 不用人像头像。每个智能体分到一种点阵球运动形态(orb),身份靠形态区分,不靠脸: 主智能体 = breathing(缓慢呼吸的环),探索者 = searching(扫描经线扫过点阵球),执行者 = working(倾斜轨道粒子); 我的智能体依次使用 weaving / connecting / composing / solving / listening / shaping。
规则:停用 = 静态帧 + 低透明;启用 = 静态帧;点击选中 = orb 动起来;运行中 = 动画 + mono RUNNING · 计时 + 行下发丝进度。 点 ▶ 播放看「运行 → 收尾 → 回到静态帧」的完整叙事。落地时直接使用 npm 包 thinking-orbs(MIT):<ThinkingOrb state={agent.orb} size={20} theme="auto" paused={!isRunning} />。
