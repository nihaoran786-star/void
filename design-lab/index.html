Void 顶栏 · 团队工作区 — 三套设计语言对比

同一内容、同一 Token 体系（--workspace-* / --color-* / 状态色），三种表达。所有方案均满足既定方向：顶栏统一 icon-slot 与左侧 2px accent 活动锚点；团队面板 header 瘦身、成员为主体、阶段折叠为一行进度。可点击导航项与成员查看选中态。

A 刻线 Ledger B 色块 Segments C 信标 Signal

刻线 Ledger 方案 A

  • 气质：编辑排版 / 账本感。只靠发丝线、字阶与一根 2px accent 竖条做层级，几乎不用背景填充。
  • 顶栏：活动项 = 竖条 + 图标上色，无底色；「新建任务」为描边按钮，与列表区用分隔线断开。
  • 团队：圆形首字头像 40px，选中 = accent 细环 + 左竖条；职责文字压到 meta 字阶。
  • 阶段：连续细进度条 + 分段刻度点，一行收完。密度最高，适合信息密集用户。

色块 Segments 方案 B

  • 气质：现代 IDE / Linear 式。行即圆角色块，hover/active 都有柔和底色，accent 竖条收进色块内左缘。
  • 顶栏：活动项 = 色块 + 内部竖条 + 图标上色；「定制」子项用左缩进 + 引导线分组。
  • 团队：圆角方形角色图标头像（沿用 lead/质检 语义色），选中 = 色块 + 竖条 + 头像染 accent。
  • 阶段：分段胶囊进度条，当前段带描边高亮。状态最"看得见"，学习成本最低。

信标 Signal 方案 C

  • 气质：运行状态驱动。「活」的信号（运行点、当前步骤）用 tone 色，结构层级仍归 accent 管。
  • 顶栏：活动项 = 通高 2px 竖条 + 浅底；自动化可带运行计数小圆点徽标；「新建任务」为虚线描边，更像"占位入口"。
  • 团队：成员为主体做到最满——46px 首字大头像 + 头像角上状态点，选中 = 竖条 + 头像染 accent，职责/分工两行弱化。
  • 阶段：点状 stepper 压成一行（圆点 + 连接线），当前步骤为空心 accent 环。
