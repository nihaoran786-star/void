HUD 线框 A1

  • 气质:仪表 HUD。1px 线框定义一切——按钮、节点都是空心描边,画布四角有取景框角标,右上 OPS·06 编号。
  • 新建任务:1px 描边幽灵按钮,右侧 N 小标;选中节点 = 描边与文字染 accent,无填充无 glow。
  • 最"硬"的高科技:像飞行器面板,信息全靠线、字距与对齐。

光电 Photon A2

  • 气质:深色控制台里的一束 accent 光。新建任务是唯一实心 accent 按钮,视觉重量集中在一处。
  • 运行路径的连线染 accent-400,运行中节点带一层极淡光晕;选中 = accent 环 + 柔光,点击切换时有 0.18s 的呼吸式过渡。
  • 状态点 2.4s 缓慢呼吸(仅运行态),整个面板像"活着"的仪器,但没有一处装饰性动画。

静默网格 Quiet A3

  • 气质:瑞士网格 + 工程图纸。没有任何按钮外壳——搜索、新建任务都是纯文字行,只用发丝底线分开。
  • 金字塔连线改为点线(dash),头像缩到 34px 让位给名字;选中 = 名字染 accent + 细环,层级全靠排版。
  • 三个版本里最安静的一版,适合长时间盯屏的工作场景。
