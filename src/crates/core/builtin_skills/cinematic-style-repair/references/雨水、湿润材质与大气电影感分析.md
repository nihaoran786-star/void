# 雨水、湿润材质与大气电影感分析

雨景真实感来自水在时间、重力、材质、光线和焦点中的连续反应，不来自把整幅画面覆盖一层水珠或蓝橙调色。

## 1. 天气状态锁定

从正在下雨、刚停雨、室内隔窗看雨、雾雨或路面残水中只选一个：

| 状态 | 必须出现 | 不要混入 |
|---|---|---|
| 正在下雨 | 迎风面受水、少量受光雨丝、持续湿润 | 大面积已经干燥的衣服 |
| 刚停雨 | 残留水珠、合并流痕、滴水、局部干区 | 整幅密集发亮雨丝 |
| 室内隔窗看雨 | 玻璃水珠与流痕、窗外受折射、室内人物可保持干燥 | 人物无原因湿透 |
| 雾雨 | 低对比细雨、远景空气衰减、近景少量水膜 | 粗大高亮雨线 |
| 路面残水 | 局部水洼、粗糙反射、轮胎或脚步扰动 | 天空仍在大雨 |

## 2. 建立五层关系

### 天气层

写清雨量、风向和快门表现。雨丝只有在主光或逆光经过的位置明显；暗部雨丝自然消失。不要让每一滴雨都发亮。

### 接触层

指定雨首先撞击哪些朝上或迎风表面：头顶、肩部、车顶、雨伞、窗台或地面。背风面、遮挡下方和门框内侧应相对更干。

### 材质层

不同材质必须产生不同响应：

- **玻璃**：水珠大小不一，部分合并后沿重力形成弯曲流痕，存在擦拭区和局部干区；水珠折射窗外亮点。
- **车漆/金属**：高接触角水珠集中在朝上面，垂直门板水珠更稀并向下合并；反射服从车身曲率。
- **织物**：吸水后颜色变深、褶皱加重，肩膀和袖口先湿；防水面料形成少量珠状水，不与皮肤或车漆相同。
- **皮肤/头发**：皮肤只在迎雨处形成不连续水膜与高光；头发结成粗细不一的湿束，根部和遮挡处保留差异。
- **沥青/泥土/木材**：沥青反射粗糙且被颗粒打断；水洼只在低处；泥土变暗并留下脚印；木材沿纹理吸水。

### 时间层

统一湿润程度：刚开始时只有迎雨面湿；持续一段时间后织物逐渐饱和；刚停雨时仍有滴落和流痕，但空中雨丝减少。检查人物、道具与环境的湿润连续性。

### 成像层

只选择一个承担清晰雨滴的景深层：镜头前、人物附近或背景受光区。其他层随焦距、光圈和快门变软或消失。雨滴不能在所有深度同时锐利，也不能形成全画面均匀白线。

不要只写“浅景深”，还要建立真实的焦平面空间距离。若要人物清晰、玻璃水珠柔化，让相机贴近玻璃并把人物放在更远处；若玻璃与人物到相机的距离接近，同时清晰可能符合光学规律，不能靠负面词强迫分离。反过来若对焦一条玻璃流痕，人物必须明显变软。

## 3. 湿地反射

反射必须同时满足：

1. 颜色来自画面中真实存在的灯或天空。
2. 延伸方向服从光源、地面透视和水洼位置。
3. 粗糙沥青打断轮廓，不形成完整镜面复制。
4. 脚步、轮胎、排水坡度或风会扰动局部水面。

没有对应光源的彩色反射、整条街同样明亮或过度平滑的镜面地面都判为失败。

## 4. 避免均匀水珠贴图

均匀水珠贴图具有这些症状：所有水珠大小接近、间距平均、亮度一致；车漆、玻璃、织物共享相同颗粒；垂直表面只有圆珠，没有合并、重力流痕或局部干区。

修订时不要增加更多“高清雨滴”。只修一个变量：降低某个表面水珠密度、增加重力合并、保留遮挡干区、改变一种材质的吸水方式，或限制清晰雨滴所在景深层。

## 5. 出租车示例

> 刚停雨的夜晚，空气中不再出现密集雨丝。黄色出租车车顶保留大小不一的圆珠；垂直后车门水珠较少，部分沿重力合并成短流痕，把手下方有一条滴水路径，门框内侧保持相对干燥。司机的防水夹克肩部有少量珠状水，脸颊只有零散水膜。湿沥青只反射画面中实际存在的暖车内灯和远处红色尾灯，反射被粗糙颗粒与浅水洼打断。焦点落在手与门把手，背景雨水自然失焦。

## 6. 硬失败检查

逐项检查：

- 天气状态是否唯一，空中雨、表面水和积水是否处于同一时间阶段？
- 不同材质是否具有不同水珠、吸水、流动和反射方式？
- 重力流痕、合并水珠、遮挡干区和局部干区是否合理出现？
- 人物、头发、衣服、道具和环境的湿润连续性是否成立？
- 是否只有一个景深层承担清晰雨滴？
- 雨丝和反射是否由实际主光照亮？

任一硬失败出现时，不用高构图分、电影调色或漂亮肤色抵消。只修最大的一层后重试。
