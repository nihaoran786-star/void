# 参考图角色与优先级路由

本文件只负责多参考图的角色分配、冲突处理和工具映射。电影感基础规则留在主 `SKILL.md`，人物、多人关系和镜头知识留在各自专题资料中。

## 1. 先把图片变成角色，而不是平均混合

逐张检查后，为每张图标记一个或多个候选角色：

- **身份参考**：脸、发型、服装、物体结构、产品形态。
- **姿态参考**：动作、手势、视线、表情和身体朝向。
- **构图参考**：景别、裁切、主体位置、留白、前中后景关系。
- **光影参考**：光源方向、软硬、反差、高光与阴影分布。
- **色彩参考**：主色、辅色、肤色关系、饱和度与冷暖。
- **纹理参考**：胶片、扫描线、故障、纸张、颗粒、材质或笔触。

同一张图可以承担多个角色，但不能默认承担全部角色。

## 2. 解析用户选择

把用户回答转换为两组约束：

### 用户优先项保留

生成后必须可见并优先评分。例如：

- `1`：图 1 的主要可见特征整体优先；若其内部仍有冲突，追问维度。
- `2`：图 2 的主要可见特征整体优先。
- `1 的人物 + 2 的光影`：图 1 锁定身份、姿态和人物结构；图 2 只迁移主光、反差和明暗组织。
- `图 1 保脸，图 2 保色彩和纹理`：脸是硬不变量；图 2 的颜色、颗粒或故障材料可增强，图 2 的人物与布局不得迁移。

### 可放宽项

用户没有点名、且与优先项冲突的维度可以调整。例如风格迁移需要更暗背景，但用户只要求保脸，则背景明度可放宽，脸部结构不能放宽。

## 3. 选择两条路由

### 角色分离

适用：身份、脸、精确姿态、产品结构、Logo 位置或构图优先。

执行：

1. 把主体结构和取景写成硬约束。
2. 从风格图只提取用户点名的光、色、纹理或成像响应。
3. 明确排除风格图中的人物、物体轮廓、道具、文字和布局。
4. 若工具允许，身份/构图图放到图像提示或内容参考位置，风格图放到样式参考位置。
5. 若工具不允许区分角色，把图号和职责直接写进自然语言提示词。

优势：身份与构图保真高。代价：强烈纹理或图形材料可能较弱。

### 双图强融合

适用：用户要求明显迁移光影、色域、纹理、故障、图形材料，并接受小幅身份或自然光漂移。

执行：

1. 两图都作为强视觉输入。
2. 先写用户点名的不变量，再写需要加强的风格维度。
3. 明确禁止搬运未指定的人物、物体、文字和布局。
4. 仅加强一到两个风格维度，不把整张风格图不加区分地复制。
5. 若身份或构图跌破优先项门槛，退回角色分离。

优势：风格证据更强。代价：人物身份、自然光或构图可能轻微漂移。

## 4. 工具映射

### 支持 Image Prompt 与 Style Reference 的工具

- 身份/构图优先：主体图作为 Image Prompt，风格图作为 Style Reference。
- 强融合：两张图都作为强图像证据；仍在文字中声明各自职责。
- 只有在工具文档明确支持时才使用权重、样式权重或专用参数。

### 只支持普通多图输入的工具

- 同时传入所需图片。
- 用“图 1 负责……；图 2 只负责……”明确角色。
- 用“不得迁移图 2 的人物/文字/布局”等语句控制污染。
- 不声称模型能绝对锁脸；用生成后评分决定是否退路由。

### 不支持图片输入的工具

- 不能把纯文字描述伪装成真实参考图复刻。
- 可提取用户能确认的视觉维度形成提示词，但要说明身份和精确构图不可验证。

## 5. 污染与退化检查

生成后逐项检查：

- 风格图的人物脸、姿态或轮廓是否混入主体？
- 风格图中的文字、Logo、道具或版式是否被误搬运？
- 为了增强纹理，是否破坏了肤色、五官或物体结构？
- 为了保身份，风格证据是否弱到不可见？
- 构图是否仍符合用户点名的裁切、位置和留白？

身份污染时退回角色分离；风格不可见但身份稳定时，只增强一个指定风格维度后重试。

## 6. 示例

输入：

- 图 1：黑发女性、藏青围巾、向画面右侧看，主体偏左且右侧留白。
- 图 2：深海军蓝背景、青绿色横向扫描光带、模拟信号故障纹理。
- 用户选择：`1 的人物 + 2 的光影和纹理`。

角色分离写法：

> 严格保留图 1 的同一人物、脸部结构、黑发运动、藏青围巾、向右视线、偏左主体和右侧留白。图 2 只提供冷青扫描光带、深蓝色域和轻微模拟故障纹理；不要迁移图 2 的轮廓、布局或任何新增物体。

双图强融合写法：

> 保住图 1 的人物可辨识度、视线、围巾和左右构图，将图 2 的青绿色扫描光带、深蓝场域和模拟通道错位明确融入环境与光线；不得让故障纹理遮盖五官，不得改变人物身份。
