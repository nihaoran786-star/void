# 短剧角色身份板

## 输入锁定

生成前确认并写入提示词：

- 角色名称、角色定位、核心情绪和视觉标志。
- 所属集数与剧情状态，包括年龄、发型、妆容、服装、伤势和情绪变化。
- 参考图负责锁定的面部、身体比例、发型和服装特征。
- 缺失的身份信息不得自行改写；先请求补充或沿用已存在的资产锚点。

## 身份板规格

创建一张艺术性的 16:9 角色身份板。使用纯白或柔和米白背景；不加入环境、道具、标志或水印。

不要创建标准网格参考表、蓝图、目录式布局或重复转面。采用高端动画工作室角色研究与艺术书结合的电影感布局：不对称、优雅、大片留白、多样图像比例和有意的不平衡。

## 构图

- 放置一个略偏离中心的大型英雄全身视角作为视觉锚点。
- 分开放置中性全身、背面、侧面、坐姿、倾斜姿势、蹲姿、俯视身体角度、仰视身体角度和富有表现力的肖像研究。
- 每个视角必须是独立、干净的角色研究，不得像同一场景的连续帧。
- 不得重叠角色图像。保持清晰分离和呼吸空间。
- 不得裁切面部、隐藏肢体、堆叠人物或合并姿势。

## 身份一致性

所有视角严格保持：

- 相同面部和面部比例。
- 相同发型轮廓。
- 相同集数与剧情状态下的服装。
- 相同身体比例、姿势语言和视觉个性。
- 清晰的脸型、发型、服装、身体、手部、姿势和表情范围，便于后续图像与视频生成。

不得把同一角色不同集数的服装或状态混入同一身份板。需要多个状态时，为每个状态分别生成资产。

## 制作研究区

- 添加 2–3 个简化的黑色角色轮廓。
- 添加带有细微情绪变化的表情研究。
- 添加面部、头发和服装关键特征的细节研究。
- 添加简约、醒目的角色 ID 块，只包含：名称、角色、核心情绪、视觉标志。
- 仅在有帮助时使用少量手写风格标签、编辑箭头或标注。

## 与电影感 Skill 协作

角色身份板还必须使用 `cinematic-style-repair` 控制可信光线、肤色、材质和成像质感。以本 Skill 的身份一致性、完整肢体、视角分离和版式要求为硬约束；电影感风格不得破坏这些约束。

## 输出检查

调用生图工具前确认：

- 画幅为 16:9，背景干净且无水印。
- 主视图和所有辅助视角互不重叠。
- 面部、手部和肢体完整可见。
- 所有视角属于同一身份和同一集数状态。
- 轮廓、服装、姿势和表情足够清晰，可作为后续生成锚点。
- 结果是制作可用的艺术性身份板，而不是场景截图或普通参考表。
