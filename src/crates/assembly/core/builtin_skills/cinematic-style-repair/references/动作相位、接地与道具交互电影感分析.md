# 动作相位、接地与道具交互电影感分析

动态画面的首要问题不是“动作够不够大”，而是时间切片是否唯一、重量是否有去处、接触是否可见。模型容易把更戏剧化的腾空姿势覆盖用户要求的落地或承重瞬间。

## 1. 先选择唯一动作相位

| 相位 | 可见证据 | 不要混入 |
|---|---|---|
| 准备 | 重心后移、关节预屈、支撑面稳定 | 腾空、落地冲击 |
| 发力 | 支撑脚压地、关节伸展、重量离开支撑面 | 完整腾空、承重结束 |
| 腾空 | 双脚离地、衣物和头发滞后、身体沿运动方向移动 | 脚底压地、膝盖承重 |
| 首次触地 | 一只脚最先接触地面、脚踝开始受力、身体仍有前进惯性 | 双脚悬空、完全站稳 |
| 承重 | 脚底明确压住地面、膝髋屈曲吸收重量、重心落在支撑腿上 | 起跳伸展、漂浮姿势 |
| 动作结束 | 重心重新稳定、惯性减弱、身体恢复平衡 | 强烈加速或腾空 |

提示词只选一行。若用户说“落地瞬间”，默认选择“首次触地”或“承重”之一，再根据画面需要明确。

## 2. 建立接地三角

接地或承重镜头至少写清三项中的两项：

1. **支撑点**：哪只脚、手、膝、座椅或道具与哪个表面接触。
2. **重量方向**：重心向前、向下、向支撑腿或向道具移动。
3. **材料响应**：鞋底贴地、膝盖弯曲、衣物滞后、软垫压缩、道具下坠或地面反作用。

好例子：

> 左脚前掌已经压住木地板，左膝弯曲承重，躯干重心向左脚上方下沉；右脚刚触地但不承重，衣摆仍沿下落方向滞后。画面定格在承重相位，不是腾空相位。

不要只写“正在落地”“有冲击力”“动态抓拍”。这些词没有提供可验证接触证据，模型容易改成更戏剧化的腾空。

## 3. 控制运动模糊

- 先锁定脸、躯干和支撑点，再指定模糊区域。
- 平移跟拍时，背景与摆动端可以沿同一方向模糊；承重脚与接触面保持可读。
- 不要同时要求全局锐利和强烈运动模糊。
- 不用模糊掩盖手脚；若支撑点因模糊消失，动作相位视为失败。

## 4. 道具交互使用角色分工

复杂道具先写每只手或身体部位的单一职责：

- 左手：承重、稳定或托住。
- 右手：推动、旋转、拉动或精细操作。
- 道具：写清重量方向、连续结构和接触位置。

示例：

> 左手隔着折叠毛巾托住锅底并承受向下重量；右手掌推开摆门。锅柄、手掌、门边和两条手臂互不穿插。

如果动作相位和道具职责都复杂，先保证动作相位与承重正确，再增加一个道具动作。不要让一只手同时握、推、拉两个物体。

### 4.1 锁定道具连接拓扑

手指完整不等于交互正确。对门把手、方向盘、工具、武器、乐器等机械或结构性道具，还要写清并检查：

1. **附着母体**：把手、旋钮、按钮或零件固定在哪个门板、机身或主体上。
2. **接触点**：哪几根手指接触零件的哪个表面，拇指和其余手指如何分工。
3. **运动件**：被拉、推、转动的是零件本身、门板还是整个道具，运动方向是否一致。
4. **连续结构**：零件与附着母体之间必须有可见连接，不能凭空悬挂，也不能在运动后留在错误位置。

示例：

> 右手四指从下方扣住固定在后排车门外侧的拉式把手，拇指压在把手上方；把手随车门一起向外移动，车门仅打开十度，手、把手和门板保持同一连接拓扑。

若手握着形似正确但未连接母体的独立零件，或把手与门板运动不一致，即使手指数量正确也判为失败。修订时只强化附着母体、接触点、运动件和连续结构，避免重写人物与光线。

## 5. 出图判定

逐项检查：

- 指定的是腾空、首次触地还是承重？结果是否处于同一阶段？
- 支撑点是否真实接触表面？
- 重心是否落向支撑点，而不是漂浮？
- 膝、髋、肩或手腕是否对重量做出合理响应？
- 运动模糊是否保留了接触证据？
- 每只手是否只有一个清楚职责？
- 道具是否连续、有重量并且不穿体？
- 零件是否连接正确的附着母体，接触点与运动件是否一致？

相位错误时，即使四肢完整、画面真实，也不能判为通过。只修改相位、支撑点、重量方向和必要材料响应后重试；保持人物、构图、光线和色彩不变。
